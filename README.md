# RETX — Coming Soon Hero (`retx.ae`)

A standalone, **hero-only** Coming Soon page built with **Tailwind CSS v4**, featuring a **fixed full-viewport background video** (`retx-video_tjg1vk.mp4`) and the final **`RX`** brand mark.

## What’s Inside

- **`index.html`** — Complete, zero-dependency, production-ready page (compiled Tailwind v4 CSS, exact vector `RX` logo & favicon, fixed full-screen background video, glassmorphic audio/replay controls, and frosted architectural bottom dock).
- **`assets/rx-logo.svg` & `assets/rx-logo.jpeg`** — Exact vector SVG recreation and original attached `RX` final logo (`#103A27` deep forest emerald, `#BB7750` burnished copper, `#819B8D` eucalyptus sage).
- **`src/input.css`** — Tailwind CSS v4 `@theme` source tokens, entrance motion, and portrait studio-blend mask.

## Responsive Fixed-Background Engineering

- **Desktop (`lg:` and up):** True `fixed inset-0` edge-to-edge `object-cover` background video with an unobstructed central viewing window and frosted `backdrop-blur-2xl` top/bottom glassmorphic controls.
- **Mobile & Tablet Portrait (`375px` iPhone SE → `390px` iPhone 15 → `768px` iPad):** Seamlessly blends the `16:9` background film into a color-matched `fixed inset-0` studio cyclorama so the `RX — Real Estate Transaction Exchange — Connect. Close. Get Paid.` reveal is never cropped at the sides of portrait screens.
